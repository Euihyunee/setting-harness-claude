## DB 관련 
### company_code [users, dept]
- company_code 는 사용자에게는 정상적으로 적혀 있지만, 부서 테이블에서는 해당 company_code 의 스펙이 유저 테이블과 동일하지 않음.
- 부서 테이블에서는 company_code 는 diningbrands 로 통일이 되어있었고, 박진규 과장님 전화 내용으로는 같은 부서 내에 사용자들이 법인이 다를 수 있는 경우가 있고, 원천에서도 제공되지 않음. 따라서 company_code는 사용자를 바라보고 사용해야 하며, 부서 테이블의 company_code 컬럼은 추후 인사 배치 로직을 점검하며 제거 마이그레이션 작업 예정되어 있음.
