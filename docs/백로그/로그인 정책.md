- 신규 유저 : 등록된 생년월일로 (yyyyMMdd) 로 최초 로그인
- 비밀번호를 잊은 경우
    - 임시 비밀번호 발급 → 등록된 이메일로 발급 요청 후 비밀번호 변경
    - 또는 관리자 문의 페이지 이동
    - 관리자는 사용자 권한 페이지에서 해당 유저 비밀번호 초기화 버튼 클릭
        - yyyyMMdd 로 초기화
- 패스워드 변경
    - 사번 / 현재 PW / NEW PW / PW 확인 입력 후 변경
- 기타
	- 비밀번호를 잊은 경우 등록된 이메일로 인증만 하고 비밀번호 변경으로 넘어가자는 이야기 있었는데 해당 사항 결정 필요
