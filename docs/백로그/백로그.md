## ✅ 확정 기능 요건 (Technical Requirements)

### 1. 보안 및 데이터 보호

- **파일 업로드 차단:** 프롬프트 입력 시 모든 형태의 파일 업로드 기능을 비활성화합니다.
    
- **데이터 비식별화:** 입력된 텍스트 중 개인정보로 식별되는 모든 정보는 전 과정에서 비식별화 처리를 수행합니다.
    
- **복사/붙여넣기 제한:** 외부 데이터의 대량 유입 및 내부 정보의 무단 유출 방지를 위해 클립보드 활용을 차단합니다.
    
- **로그 관리 최소화:** 프롬프트 저장 기간을 최소화하고, 로그 백업을 엄격히 제한합니다.

## 🚫 답변 제한 가이드라인 (Constraint Rules)

봇이 직접적인 법적 판단을 내림으로써 발생할 수 있는 리스크를 방지하기 위해 아래 유형의 질문에는 답변하지 않습니다.

### 1. 포괄적 적법성/위법성 판단 요청

- **사유:** 오해의 소지가 있는 "문제없음" 답변이 모든 법령 위반에 대한 면죄부로 해석될 위험 방지
    
- **제한 예시:** * “개인정보 동의서를 이렇게 작성하면 문제 없지?”
    
    - “같은 그룹사 내에서는 수집한 개인정보를 공유하면 문제가 될까?”
        

### 2. 규정 위반 허용 여부 문의

- **사유:** 회사가 탈법이나 위법 행위를 조장한다는 대외적 오해 및 법적 리스크 차단
    
- **제한 예시:**
    
    - “관련 서류를 즉시 파기하라고 되어 있는데 좀 있다 파기해도 괜찮겠지?”
