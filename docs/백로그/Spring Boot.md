## ✅ 지식 문서 파일 관련 
### 에이전트 RAG
- 파일을 업로드하면 직접 파싱하는 도구를 이용해서 운영 담당자가 벡터화 후 저장한다. 
- 해당 파싱 도구는 플랫폼 내에 있으며 시스템 관리자가 사용할 수 있도록 `우리끼리 결정` 
- 챗봇 RAG
	- 모든 사용자가 사용할 수 있음
	- RAG 파일에는 법인별/매장본사 여부를 선택할 수 있으며 이에 따라 사용자의 정보를 기준으로 RAG 범위를 정한다. 
### 지식 파일 RAG
- 파일 탐색 
	- 사용자의 부서를 기준으로 `하위 부서에 있는 기본 파일`을 재귀 탐색하고, 사용자 부서의 지식 파일 
	  = **하위 부서 기본 파일** + **사용자 부서 파일** + **사용 범위로 지정된 파일**
