## settings.json 템플릿

```json
{
  "env": {
    "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1",
    "CLAUDE_CODE_MAX_OUTPUT_TOKENS": "64000"
  },
  "permissions": {
    "allow": [
      {기술 스택에 맞는 allow 규칙들}
    ],
    "deny": [
      "Read(./.env)",
      "Read(./.env.*)",
      "Read(./secrets/**)",
      {추가 민감 경로}
    ]
  }
}
```

**기술 스택별 allow 규칙 예시:**

Node.js/npm 프로젝트:
```json
"Bash(npm run *)", "Bash(npx *)", "Bash(node *)"
```

Python 프로젝트:
```json
"Bash(python *)", "Bash(pytest *)", "Bash(pip install *)", "Bash(alembic *)"
```

Git (모든 프로젝트):
```json
"Bash(git status)", "Bash(git diff *)", "Bash(git add *)", "Bash(git commit *)", "Bash(git log *)"
```

Docker:
```json
"Bash(docker build *)", "Bash(docker-compose *)"
```
